# data-analysis-portfolio
# 个人数据分析项目集

这里收录了我用 Python 进行数据分析与建模的 Jupyter Notebook 项目。

## 项目列表

### 1. 航空公司客户价值分析
- **文件**：[airline-customer-value.ipynb](./airline-customer-value.ipynb)
- **内容**：使用 K-Means 聚类对航空客户进行分群，构建 LRFMC 模型，并绘制雷达图进行客户画像分析。

### 2. 民宿评分影响因素分析
- **文件**：[homestay-rating-analysis.ipynb](./homestay-rating-analysis.ipynb)
- **内容**：基于携程民宿数据，通过多元回归与决策树模型，分析影响民宿总评分的核心因素。

### 3. 财政收入影响因素分析
- **文件**：[fiscal-revenue-factors.ipynb](./fiscal-revenue-factors.ipynb)
- **内容**：结合 Lasso 特征选择、灰色预测 GM(1,1) 与 LinearSVR，对财政收入进行建模与预测。
